这句话也一直是我的座右铭：

> 天将降大任于斯人也，必先苦其心志，劳其筋骨，饿其体肤，空乏其身，行拂乱其所为，所以动心忍性，增益其所不能。

做这个项目的过程里，我也时常拿它鼓励自己。

## 为什么做这个项目

这个项目陆陆续续写了三年，经历了三次大的版本更迭。最初只是给自己公司用，解决一些工作中实际遇到的问题。

后来慢慢有了一个念头：既然已经做了这么多，为什么不整理成一个开源项目，让有类似需求的人也能用上？我想做一个内置 AI Agent 的后台管理项目，让大家在它的基础上，继续做出自己的东西。

于是，就有了 DuShan AI Native。

一路做下来，我很庆幸赶上了 AI 工具快速发展的这几年。最早是在 ChatGPT 3.5 网页里提问、复制粘贴代码，后来用上 Cursor 的 Tab 补全，再后来，各种 AI 编程 IDE 和命令行 Agent 陆续出现。工具在变，模型的能力也在变，许多以前觉得难以实现的想法，开始可以一点点做出来了。

这让我觉得，当初选的这条路，还可以继续走下去。

## 关于 AI，也关于想做点什么的人

我觉得，AI 给了普通人一个很难得的机会：有了想法，可以更快地动手试一试。

过去，一个念头可能因为时间、成本，或者自己暂时不会某项技术，就一直搁在那里。现在，借助一个合适的开源框架，再配合 AI 编程工具，我们有机会用更少的时间，把想法做成一个能运行的初版，再看看它到底有没有用。

这也是我希望这个项目能带来的帮助：替你省下一些搭基础的工夫，让你能早点开始做自己真正想做的部分。

如果你也有过被说成“纸上谈兵”或“天马行空”的想法，也许现在可以重新拿出来试试。先做一点，再慢慢往前走。

## 最后，想对你说

这三年走得并不顺利。不过，看到项目一点点完善，bug 一个个修好，想法一次次变成能用的功能，我就已经很满足了。

把它开源，也是希望这些积累能在我自己的需求之外，再帮到一些人。哪怕只是让你少踩一个坑、少花一点时间，或者给了你一点启发，我都会觉得，这些年的折腾挺值得。

如果你用着有什么不顺手的地方，或者有自己的想法，欢迎提出来。能一起讨论、一起把它改好，也是我期待的开源生活。

谢谢你读到这里。希望 DuShan AI Native 能帮你做出一点自己想做的东西。
